# 排行榜接口契约

来源：开发者提供的最新 API接口文档.md，第14.1节。


### 14.1 团队业绩排行

- **请求方法：** `GET`
- **接口路径：** `/api/rankings/team_kpi`
- **认证要求：** 必须登录（Bearer JWT）
- **业务说明：** 当日团队业绩前 50 名，只含 `team_kpi` 大于 0 的用户。先按团队业绩倒序，再按用户 ID 升序。空榜仍返回 `me`。`me.rank` 为 `0` 表示本人团队业绩不大于 0；大于 0 时名次可以超过 50。榜上地址是脱敏地址。业绩每天 00:05 清零。

#### 请求参数

无路径参数、查询参数或额外请求头参数。

#### 请求体（`application/json`）

无。

#### 成功返回（HTTP 200，`application/json`）

| 返回字段 | 类型 | 必返 | 中文说明 | 枚举/格式/示例 |
| --- | --- | --- | --- | --- |
| list | array | 是 | 前 50 名 | 无数据时为 `[]`，最多 50 条 |
| list[].rank | integer | 是 | 名次 | 从 1 开始 |
| list[].address | string | 是 | 脱敏地址 | 前 5 位 + `...` + 后 4 位 |
| list[].team_kpi | string | 是 | 团队业绩 | 去掉末尾 `0` |
| list[].kpi | string | 是 | 个人业绩 | 去掉末尾 `0` |
| me.rank | integer | 是 | 我的名次 | 未入统计时为 `0`，可以大于 50 |
| me.team_kpi | string | 是 | 我的团队业绩 | 去掉末尾 `0` |
| me.kpi | string | 是 | 我的个人业绩 | 去掉末尾 `0` |

返回示例：

```json
{
  "list": [
    {
      "rank": 1,
      "address": "0x529...9EE7",
      "team_kpi": "500",
      "kpi": "100"
    }
  ],
  "me": {
    "rank": 3,
    "team_kpi": "80",
    "kpi": "10"
  }
}
```

#### 可能错误

| HTTP 状态码 | 中文说明 |
| --- | --- |
| 400 | 用户被封禁 |
| 401 | Token 缺失或无效 |
| 500 | 服务器内部错误 |
