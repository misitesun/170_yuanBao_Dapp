# Minimal React Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create and verify a minimal React 19 learning project in the current directory.

**Architecture:** Use the official Vite React TypeScript template as the complete application skeleton. Keep the generated React entry point and root component, without adding routing, networking, state management, styling preprocessors, Web3, internationalization, UI libraries, or extra test libraries.

**Tech Stack:** React 19, React DOM, TypeScript, Vite, ESLint

## Global Constraints

- Use the official Vite `react-ts` template.
- Do not install application libraries beyond the template dependencies.
- Keep the project intentionally small for incremental teaching.

---

### Task 1: Scaffold the application

**Files:**
- Create: `package.json`
- Create: `index.html`
- Create: `vite.config.ts`
- Create: `eslint.config.js`
- Create: `tsconfig.json`
- Create: `tsconfig.app.json`
- Create: `tsconfig.node.json`
- Create: `src/main.tsx`
- Create: `src/App.tsx`
- Create: `src/App.css`
- Create: `src/index.css`

**Interfaces:**
- Produces: a Vite application whose root component is `App` from `src/App.tsx`.

- [ ] **Step 1: Generate the official template**

Run: `npm create vite@latest . -- --template react-ts --no-interactive`

Expected: Vite creates the React TypeScript files in the current directory.

- [ ] **Step 2: Install declared dependencies**

Run: `npm install`

Expected: dependencies install and a lockfile is created.

### Task 2: Verify the scaffold

**Files:**
- Verify: `src/main.tsx`
- Verify: `src/App.tsx`
- Verify: `package.json`

**Interfaces:**
- Consumes: the Vite project generated by Task 1.
- Produces: evidence that linting, TypeScript compilation, production bundling, and browser rendering work.

- [ ] **Step 1: Run ESLint**

Run: `npm run lint`

Expected: exit code 0 with no lint errors.

- [ ] **Step 2: Run the production build**

Run: `npm run build`

Expected: exit code 0 and generated files under `dist/`.

- [ ] **Step 3: Start the development server**

Run: `npm run dev -- --host 127.0.0.1`

Expected: Vite reports a local development URL.

- [ ] **Step 4: Verify the page in a browser**

Open the reported URL and confirm that the starter React page is visible without console errors.
