# Minimal React Scaffold Design

## Goal

Create a minimal React learning project for an experienced Vue 3 developer. Keep the initial dependency surface small so each later addition can be introduced and explained separately.

## Included

- React 19
- React DOM
- TypeScript
- Vite
- ESLint
- The standard Vite React TypeScript entry files
- A minimal page proving that the application mounts correctly

## Excluded

- Axios
- Routing
- State-management libraries
- Sass and PostCSS viewport conversion
- Web3 and wallet libraries
- Internationalization
- UI component libraries
- Additional testing libraries

## Structure

The project uses Vite's React TypeScript template. `main.tsx` mounts the root React component, while `App.tsx` is the first component used for teaching JSX and component rendering.

## Verification

- Dependencies install successfully.
- TypeScript and Vite production build succeeds.
- ESLint succeeds.
- The development page renders in a browser.
