# 充值地址契约

来源：开发者最新 API接口文档.md 第5.5节。充值链 BSC20 固定由开发者确认，不是接口返回字段。


- **请求方法：** `GET`
- **接口路径：** `/api/users/my/recharge_address`
- **认证要求：** 必须登录（Bearer JWT）
- **业务说明：** 返回当前用户的 USDT 充值地址。库里还没有地址时，向链上申请并保存 checksum 地址。申请失败返回 400，正文 `获取充值地址失败`。

#### 请求参数

无路径参数、查询参数或额外请求头参数。

#### 请求体（`application/json`）

无。

#### 成功返回（HTTP 200，`application/json`）

| 返回字段 | 类型 | 必返 | 中文说明 | 枚举/格式/示例 |
| --- | --- | --- | --- | --- |
| recharge_address | string | 是 | USDT 充值地址 | checksum 地址 |

返回示例：

```json
{
  "recharge_address": "0x52908400098527886E0F7030069857D2E4169EE7"
}
```

#### 可能错误

| HTTP 状态码 | 中文说明 |
| --- | --- |
| 400 | 用户被封禁，或获取充值地址失败 |
| 401 | Token 缺失或无效；地址请求头与 token 用户不一致 |
| 500 | 服务器内部错误 |
