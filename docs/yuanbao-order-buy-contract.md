# 抢拍提交契约

来源：开发者《元宝卡买卡抢购接口.md》（2026-10-12）。买卡与抢购统一数量契约见 yuanbao-card-purchase-contract.md。

 抢购

- **请求方法：** `POST`
- **接口路径：** `/api/orders/buy`
- **认证要求：** 必须登录（Bearer JWT）
- **业务说明：** 买方抢购，quantity可选，默认1，支持1–100整数张。扣该产品配置的 USDT 单价 × 张数和宝气单价 × 张数。必须 `can_buy` 为 `true`。全平台今日该产品已抢张数 + 本次张数不能超过今日买卡张数，且剩余库存至少为本次张数。数量或余额不足整单失败；成功后库存减本次张数。成功体为 `[]`。

#### 请求参数

无路径参数、查询参数或额外请求头参数。

#### 请求体（`application/json`）

| 字段 | 类型 | 必填 | 中文说明 | 约束/示例 |
| --- | --- | --- | --- | --- |
| product_id | integer | 是 | 产品 ID | ≥ 1 |
| quantity | integer | 否 | 抢购张数 | 1–100，不传为1 |

请求示例：

```json
{
  "product_id": 1,
  "quantity": 2
}
```

#### 成功返回（HTTP 200，`application/json`）

空数组 `[]`。

返回示例：

```json
[]
```

#### 可能错误

| HTTP 状态码 | 中文说明 |
| --- | --- |
| 400 | 用户被封禁；元宝卡功能未开启；当前不在抢购时间；该产品已抢购完；可抢数量不足；产品不存在或已下架；余额不足；服务器繁忙请稍后再试 |
| 401 | Token 缺失或无效 |
| 422 | 产品 ID 或数量校验失败 |
| 500 | 服务器内部错误 |
