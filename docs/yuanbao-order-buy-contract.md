# 抢拍提交契约

来源：开发者 API接口文档 (2).md。

 抢购

- **请求方法：** `POST`
- **接口路径：** `/api/orders/buy`
- **认证要求：** 必须登录（Bearer JWT）
- **业务说明：** 买方抢购，每次一张，扣该产品配置的 USDT 和宝气。必须 `can_buy` 为 `true`。全平台今日该产品已抢购张数不能达到已买卡张数，且剩余库存至少 1。成功后库存减 1。成功体为 `[]`。

#### 请求参数

无路径参数、查询参数或额外请求头参数。

#### 请求体（`application/json`）

| 字段 | 类型 | 必填 | 中文说明 | 约束/示例 |
| --- | --- | --- | --- | --- |
| product_id | integer | 是 | 产品 ID | ≥ 1。每次抢购一张 |

请求示例：

```json
{
  "product_id": 1
}
```

#### 成功返回（HTTP 200，`application/json`）

空数组 `[]`。

返回示例：

```json
[]
```

#### 可能错误

| HTTP 状态码 | 中文说明 |
| --- | --- |
| 400 | 用户被封禁；元宝卡功能未开启；当前不在抢购时间；该产品已抢购完；抢购数量超过今日买入数量；产品不存在或已下架；余额不足；服务器繁忙请稍后再试 |
| 401 | Token 缺失或无效 |
| 422 | 产品 ID 校验失败 |
| 500 | 服务器内部错误 |
