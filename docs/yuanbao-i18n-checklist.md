# 元宝多语言翻译

## 范围与依据

2026-09-29 开发者明确要求进行多语言翻译。依据 src/i18n/README.md、APP_LANGUAGES、PROJECT_TERMS.md 与当前页面源码；五种语言为简体中文、繁体中文、英语、日语、韩语，不新增语言或依赖。

目标：登录开屏、首页、导航、资产、团队、公告列表/详情/弹窗，以及已有抢拍、卡包、排行榜、充值/提现/记录/转账弹窗的固定文案和无障碍标签可以切换。模板 showcase 文案、未使用的历史静态公告数据不在生产文案范围内。

## 影响与实现

- 源文案：新增五份 locales/project 语言包；common 包补共享加载和下拉标签，common/dappH5 包补通用请求与钱包错误。加载器按 common → dappH5 → project 合并，仍按需加载。
- 页面消费：useTranslation 负责订阅语言变化。Tab 和指标标签在渲染时翻译；时间、排名、等级等使用插值；高亮标题通过 Trans 保留 span，并按完整语句翻译。
- 内容边界：首页三个英文卡牌名称保留；金额/地址/邀请码/哈希/时间数值不改。公告 HTML、流水 content、等级 name、成员 maddress 等后端内容原样展示。通用 HTTP Toast 仅翻译前端两项默认错误，后端错误信息原样展示。
- 公共组件：Dropdown、Picker、DropletLoading、PagePullRefresh、LanguageSwitch 仅翻译默认文案及标签，保留 props、布局、刷新门控、分页、选中和关闭契约。
- 兼容性：英文/日文/韩文使用页面局部 :lang 规则，长标题、标签和说明允许扩展或换行；这些是多语言适配，未声称为 Figma 实测尺寸。中文源尺寸保持，首页卡包标题区以 min-height 容纳换行。
- API/钱包/存储/路由：协议、字段、金额、签名、会话及路由保持既有逻辑。语言列表与缓存键不变，合法缓存语言优先；语言选择后沿用原加载资源、保存语言并刷新页面的机制，以新 lang 头获取后端内容。
- 回退：英文 fallback 保持。回滚本次语言包、loader 与页面翻译调用即可，不需要数据迁移。

## 验证

- tests/i18n-project.test.mjs：五种语言键/插值/富文本标签一致、无固定中文 JSX 漏译、真实 React/i18next 切换语言、金额和远端内容保持。
- 已有业务回归仅增加翻译边界 stub；中奖时间改为完整插值字符串，对应断言检查显示内容。
- pnpm lint、pnpm test、pnpm exec tsc -b、pnpm build、git diff --check。
- 本地浏览器通过隔离验收页检查页面和语言选择，不绕过真实登录路由、不写入钱包或授权状态；临时验收入口完成后移除。真实钱包与生产后端的多语言公告/流水仍需设备联调。
