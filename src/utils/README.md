# Utils
通用工具。

This directory stores pure utility functions that do not depend on React and do not create side effects.
这个目录存放不依赖 React 且不会产生副作用的纯工具函数。

If a utility needs storage, network, DOM or platform access, place it under `services` or `shared` instead.
如果工具需要访问存储、网络、DOM 或平台环境，应优先放到 `services` 或 `shared` 中。
