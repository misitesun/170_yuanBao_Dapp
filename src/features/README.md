# Features
业务功能模块。

This directory stores business capability modules that group API calls, types and future query logic by domain.
这个目录存放按业务能力划分的模块，把接口、类型以及后续查询逻辑按领域组织在一起。

Create a new feature when a capability has its own API contract or page-facing data model.
当某个能力拥有独立接口契约或面向页面的数据模型时，就创建新的 feature。
