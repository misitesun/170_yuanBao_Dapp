# 公告接口

列表、详情为公开请求，主动不带旧Token；弹窗及已读当前仅在已登录业务页面使用。分页列表使用notices包裹，详情为裸对象，弹窗notice为对象或空数组，严格区分。is_show决定弹窗显示，不等同公告不存在。markNoticeRead虽使用GET但修改已读状态，只等待成功，不解析无消费者的返回体。错误由HTTP公共链路处理。HTML通过content.tsx白名单转React元素；html.ts只提供HTTP(S) URL检查、清理DOM和纯文本摘要。类型公告与游客已读因文档问题不接入。请求语言保持原zh-Hans等值，不转zh-CN。

## 多语言

弹窗我已阅读和本地错误提示接入五种语言；远端标题/正文与未使用成功响应的处理保持。
