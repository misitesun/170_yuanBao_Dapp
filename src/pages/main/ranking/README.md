# 元宝排行榜

依据 Figma `30230:644` 与开发者确认的 `docs/yuanbao-ranking-checklist.md`。通过现有MainLayout访问 `/ranking`，侧栏新增“排行榜”入口，点击使用既有NavLink关闭侧栏并导航。保留公共Header、Popup、钱包和鉴权边界。

本阶段展示原稿1–9名静态数据：前三名使用人工导出徽章，其余两位数名次。我的排名是开发者明确要求的固定视口底部覆盖层，底29px加设备安全区，列表预留179px加安全区，末行可完整滚到卡片上方。固定区域层级低于公共Header与Popup；卡内部使用Grid/Flex，光晕与星空仅是带例外标记的非交互装饰。

源750px数值保留交给px-to-vw转换；字体沿用已批准微软雅黑。原始浮点颜色保留主题token，底板使用690×144人工PNG，缺少的光晕按原稿圆形图层及裁切参数实现。静态地址和金额不是当前钱包数据；不新增排序、分页、刷新、API或合约协议。真实数据和加载行为待后续文档确认。

验证：pnpm exec tsc -b、pnpm lint、pnpm test、pnpm build（保留品牌门禁）、git diff --check；浏览器在750/375宽度检查路由、侧栏关闭与激活态、固定卡滚动位置、末行可见与遮挡层级。
