# 充值

`DepositPage` 是 `/deposit` 二级静态页，资产页充值按钮通过 `useAppNavigate` 进入；位于 MainLayout 外，复用 SecondaryHeader 的返回、标题和右侧记录插槽，不改变公共 Header/侧栏。设计参考为其他项目 Figma 29534:12578，量测、资源、适配差异见 `docs/yuanbao-deposit-checklist.md`。

保留信息卡、二维码和提示布局，开发者明确忽略金额输入框与确认充值按钮。全部配色引用现有公共 token，二维码四角用原 SVG 作为主题色蒙版，原二维码白色底板保持圆角切图，码图作为设计示例按300×300展示。正文全部正常流/Grid布局，无定位例外。

USDT仅为当前静态币种示例，选择器复用 Picker；充值链未配置，空选择器使用公共 Empty。地址显示 `--`，复制按钮禁用，不写剪贴板、不冒充真实充值地址。顶部记录按钮进入 /deposit/records 静态充值记录页。示例二维码明确标注，源稿的 TRX20、伪地址和最低0.01USDT规则均未写入本项目。没有API、合约、提交或占位刷新。

共享 SecondaryHeader 保持既有100px及安全区布局；源设备状态栏不实现。文字行高未被Figma MCP暴露的部分按39/36px排版并记录为估算，字体沿用微软雅黑；记录SVG含描边导出66×66，保留导出原始尺寸。源两块表单省略后说明区随内容上移，布局与配色差异均为已确认的项目适配。

## 多语言

固定文案、状态和无障碍标签接入五种语言，静态数值与交互边界保持。说明与富文本标题的处理见 docs/yuanbao-i18n-checklist.md。
