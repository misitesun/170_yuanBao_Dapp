# 我的卡包

星空背景已按开发者要求提升到 `src/assets/common/account-background.png`，供卡包和资产页引用同一份文件。此页仅更新资源URL，图片字节、背景尺寸和布局保持原样。

`CardPackPage` 对应 `/card-pack`，由首页卡包入口和侧栏“我的卡包”进入，保持公共 MainLayout/Header 的结构与交互。视觉来源为 Figma 拍出`30183:311`、拍入`30204:4176`、释放`30204:4308`，精确参数、资源及设计差异见 `docs/yuanbao-card-pack-checklist.md`、`docs/yuanbao-card-pack-incoming-checklist.md`与`docs/yuanbao-card-pack-release-checklist.md`。

当前为静态设计开发。本地 `service.ts` 提供有限的两页设计示例：每页3项，拍出首屏红/蓝/绿及100/300/1,000与时间来自原稿；拍入首屏109+1、309+3、1030+10及逐项本金标签来自新稿，不拆分金额或计算汇率；释放/进行中的三张收益卡均按源稿保留109+1、中奖时间、286.00/46.00/6.124875/1.293846/20/180。各组第二页重复其源示例、内部ID独立，用来验证增量加载；不代表钱包资产、真实订单、实际收益或API响应。中奖/未中奖及释放/已完成没有独立数据，使用共享Empty，不推导释放动作、收益计算或奖励。默认进入仍为拍出/待开奖。

`pagination.ts` 为页面本地状态，通过useSyncExternalStore订阅；替换列表先同步清空数据、页码、hasMore与加载门控，再await第一页。使用递增generation丢弃过时结果，包括旧的加载更多与错误；同页并发只执行一次。失败保持页码供重试，卸载失效请求。数据源作为参数注入，后续提供API Markdown后在独立联调范围内替换，不假定后台分页协议。

PagePullRefresh只包裹此业务页面。usePageRefresh等候第一页真实重新加载，初始或下一页加载期间禁用；usePageLoadMore在第一页加载期间关闭、hasMore=false，通过droplet展示公共内联动画，空列表不显示“没有更多了”。组件已有的新scroll事件启用观察器机制保持不变。

订单类型三项、开奖状态三项、释放状态两项复用SegmentedTabs的button、键盘与焦点能力，页面局部禁用其渐变底板，按本页实测文本/内阴影样式适配；不添加设计外胶囊动效。拍入/释放选中时按对应的128px未选中/160px选中宽、30px gap和垂直居中还原，拍出维持原稿未选中文字8px偏移。释放时状态组每项340×76、gap14，列表690×426、gap20；收益正文为article及dl，两排三列指标，保留首列9px与其余10px图层间距。正文为Flex/Grid正常流，只有星空和不承担布局的描边装饰为声明的background-art例外。

本地查询以判别联合区分普通开奖状态pending/won/lost与释放状态ongoing/completed；数据记录也区分card/release，不给收益卡添加虚构的卡名或颜色。进入释放重置ongoing，离开释放重置pending，拍出/拍入之间保留有效开奖状态；点击当前类型不重置其状态。切换同步执行分页替换及旧结果隔离。释放改用“中奖时间”原文，不误用购买时间；两处双币叠加复用本地DualCurrencyIcon。

拍入本金的双币效果按开发者指示复用资产页common/token-usdt.png与token-baoqi.png，各显示52×52、宝气错开30px、重叠22px，Grid容器82×52；不重画图标，也不要求额外组合资源。两张原图自然40×40，内部宝气留白及阴影比例与新52px图层有细微差异，作为明确的复用决定记录在清单。拍出仍使用原元气图片，不混用宝气。原稿红卡标签为“本金(USDT+宝气）”、蓝绿为“本金(元气）”，逐项保留该设计差异。

开发者确认默认微软雅黑，代替原稿Alibaba PuHuiTi/Poppins/PingFang SC；字号、字重、行高和字距仍为原稿值。字形差异属于批准的设计差异。使用本页7张手动导出图及精确导出的52×52红卡本金组合图，卡牌/元气/分隔图引用common同一份资源。

## 多语言

固定文案、状态和无障碍标签接入五种语言，静态数值与交互边界保持。说明与富文本标题的处理见 docs/yuanbao-i18n-checklist.md。

2026-09-30 展示术语按 `PROJECT_TERMS.md` 统一：固定文案中的 USDT 显示为“余额”，并使用五种语言对应译文；内部资产标识、选择器值、字段名和后端原文保持原值。该规则覆盖本文历史展示文案说明。

同日开发者红框更正：释放订单中 `totalUsdtIncome`、`todayUsdtIncome` 的展示标签分别为“累计收益(元气)”“今日收益(元气)”，同步五种语言；该局部规则覆盖前述余额术语。本金、宝气收益、金额和内部字段保持现状。
