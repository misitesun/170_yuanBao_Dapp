# 提现

`WithdrawPage` 对应二级静态路由 `/withdraw`，资产页提现按钮通过 `useAppNavigate` 进入；路由位于MainLayout外，复用SecondaryHeader的顶部、返回及右插槽，不新增双Header或改变侧栏契约。设计源为Figma 29534:12621，精确量测、资源核对和适配差异见 `docs/yuanbao-withdraw-checklist.md`。

保留币种/链信息卡、提现数量、可用余额及手续费展示。开发者已修正提现页范围，正常展示共享Input、“全部”及提现按钮；受控输入保留本地值，提交按钮和回车阻止默认提交，仅提示提现功能待接入。“全部”在余额未配置时提示待配置，不写入伪余额。没有二维码、地址表单、API、合约、真实提现提交或占位刷新。

币种USDT为静态示例，Picker只提供该项；链选项未确认，空Picker展示公共Empty。可用余额为 `-- USDT`，手续费及提现链为待配置，不沿用其他项目的示例余额、TRX20和0.1%费率。记录按钮进入 /withdraw/records 静态提现记录页。

主题配色全部引用现有公共token，布局用正常流和Flex，无页面定位例外。记录及箭头与充值页资源一致，复用其完整SVG，保持导出根尺寸；不重绘。字体沿用微软雅黑，未暴露的行高39/34px属于记录在清单中的排版估算。输入103px、圆角20px，按钮88px、圆角999px，使用共享渐变焦点描边与full-button mixin，恢复源设计输入→手续费→按钮的间距。充值页仍保留其原有排除规则。
